# multi-agent-qa

링크와 프롬프트를 주면 AI가 웹 서비스를 탐색하고, **목표·관찰·판단 요약·행동·결과·의심·검증을 텍스트로 실시간 보고**하는 로컬 QA 스튜디오입니다.

에이전트 A~E 5명 중 사용자가 선택한 한 명만 직접 실행합니다. 역할·순서는 자유롭고 자동 병렬 실행·대기열·에이전트 간 자동 공유는 없습니다. 첫 기본 대상은 [모여](https://moyeo-web.vercel.app/login)이며 다른 웹 서비스도 설정할 수 있습니다.

AI는 DOM 텍스트와 요소 정보로 탐색합니다. 내부 사고 과정 원문을 표시하거나 화면 이미지를 모델에 보내는 방식이 아닙니다. 스크린샷과 trace는 **기본 꺼짐**입니다.

## 핵심 사용 흐름

1. 테스트 설정에서 서비스 URL·공통 지침을 저장합니다.
2. 에이전트별 역할·계정 별칭·이번 작업 프롬프트를 입력합니다.
3. 필요하면 전용 브라우저를 열어 테스트 계정으로 직접 로그인합니다.
4. 실행 버튼을 누르고 실시간 활동 보고를 확인합니다.
5. AI가 목표를 마치면 ‘종료 대기’ 상태가 됩니다. 불필요한 추가 호출은 하지 않습니다.
6. 원할 때 **종료하고 피드백**을 누릅니다. 실행 중·일시정지 중에도 사용할 수 있습니다.
7. 새 조작을 막고 진행 중 조작을 정리한 뒤, 피드백을 생성하고 브라우저를 닫습니다.
8. 발견 사항과 Markdown/JSON 리포트를 확인합니다.

‘긴급중단’은 즉시 취소·프로세스 종료를 위한 별도 기능입니다. 종료 후 AI 피드백 생성과 동일하지 않습니다. 취소한 기록은 나중에 ‘종료하고 피드백’으로 정리할 수 있습니다.

## 시작하기 · Windows PowerShell

Node.js **22.16 이상**이 필요합니다. Node 내장 SQLite를 사용하며 Node 22에서는 experimental 경고가 나올 수 있습니다.

```powershell
git clone https://github.com/ohujj/multi-agent-qa.git
cd multi-agent-qa
npm.cmd ci
npm.cmd run browser:install
if (-not (Test-Path -LiteralPath '.env')) {
    Copy-Item -LiteralPath '.env.example' -Destination '.env'
}
notepad .env
```

키는 사용자 본인이 로컬 .env에 입력합니다. 실제 키를 채팅·프롬프트·React 코드·VITE_ 환경변수에 넣지 않습니다.

```dotenv
OPENAI_API_KEY=사용자의_OpenAI_API_키
OPENAI_MODEL=계정에서_사용할_수_있는_모델_ID
```

도구 호출이 가능한 OpenAI API 모델이 필요합니다. 별도 API 비용이 발생할 수 있습니다. 키·모델의 존재만 확인하며 실제 유효성은 실행 시 확인됩니다. 값이 없으면 AI 실행은 비활성화됩니다.

```powershell
npm.cmd run check
npm.cmd run build
npm.cmd start
```

기본 접속: [http://127.0.0.1:4310](http://127.0.0.1:4310). 개발은 `npm.cmd run dev` 후 [http://127.0.0.1:5173](http://127.0.0.1:5173). 종료는 터미널 Ctrl+C입니다.

전용 브라우저는 기본 표시됩니다. 로그인 프로필을 준비한 뒤 창 없이 실행하려면 로컬 HEADLESS=true 설정을 사용할 수 있습니다. 헤드리스 상태에서는 대화형 로그인 화면을 직접 사용할 수 없으므로 다시 로그인이 필요하면 표시 모드로 돌아가야 합니다.

브라우저 바이너리는 .local/browsers에 설치됩니다. Playwright 버전을 바꿨다면 browser:install을 다시 실행하세요.

## 활동 보고와 화면 증거

실시간 활동은 유형별로 필터링할 수 있습니다.

- 목표: 사용자가 요청한 작업.
- 관찰: 페이지 제목·요소 등의 확인 내용.
- 판단 요약: 다음 행동의 목적과 관찰 근거를 짧게 설명한 AI 요약.
- 행동·결과: 실제 도구 호출과 결과. 호출 성공이 서비스 반영 성공을 뜻하지는 않습니다.
- 의심·미확인: 아직 증명되지 않은 가설.
- 검증: AI 관찰 또는 사용자가 별도로 확인할 사항.
- 피드백: 종료 후 전체 기록 정리.

AI 요약과 시스템 기록을 구분합니다. 내부 사고 과정 원문이나 모델의 모든 숨은 판단을 제공하지 않습니다.

테스트 설정의 **스크린샷 저장**:

| 설정 | 동작 |
| --- | --- |
| 꺼짐 · 기본 | PNG와 trace를 생성하지 않음 |
| 발견·오류 시 | 명시적인 발견 기록·액션 오류 때만 PNG 저장. trace 없음 |
| 모든 액션 | 액션 후 PNG와 실행 trace 저장 |

이미지는 모델 입력으로 전송하지 않습니다. 설정을 꺼도 이전 파일을 삭제하지 않습니다. DOM으로 확인하기 어려운 배치·색·이미지·canvas 등은 이 모드의 한계입니다.

## 실행 제어와 초기화

| 상태·제어 | 의미 |
| --- | --- |
| 실행 | 동기적으로 직렬 잠금 획득. 동시 요청은 409로 거부 |
| 일시정지 | 다음 모델 요청·도구 경계에서 대기. 진행 중 액션이 즉시 취소되지는 않음 |
| 재개 | 이전 요소 ref를 무효화한 뒤 이어감. 재관찰이 필요할 수 있음 |
| 종료 대기 | AI 작업 완료. 대화를 유지하고 추가 지시 또는 종료 요청 대기 |
| 종료하고 피드백 | 조작 종료 → 기록 정리 → 도구 없는 AI 피드백 → 브라우저 종료. 정리 중 직렬 잠금 유지 |
| 긴급중단 | API 취소와 worker/브라우저 종료. 종료 확인까지 잠금 유지 |
| AI 정리 실패 | 완료를 꾸며내지 않고 기록 기반 보고서로 대체 |
| 새 테스트 | worker·브라우저 종료, 5명의 대화·현재 결과·상태 초기화 |

새 테스트에서도 역할·프롬프트·계정 별칭·대상 설정·로그인 프로필은 유지합니다. 원격 서비스 데이터는 삭제하지 않습니다. 이전 테스트는 SQLite에 남지만 재조회 UI는 아직 없으므로 초기화 전에 리포트를 내보내세요.

기본 실행 제한은 모델 25턴·180초입니다. 일시정지 시간도 포함합니다. 피드백 모델 요청은 기본 45초 제한이며 이미 진행 중인 브라우저 액션을 기다리는 시간은 별도입니다. MAX_TURNS, RUN_TIMEOUT_SECONDS, FEEDBACK_TIMEOUT_SECONDS, PORT 설정 후 재시작할 수 있습니다. 턴·시간은 금액 기준의 비용 상한이 아닙니다.

이미 서비스에 전송된 쓰기 요청은 취소해도 반영될 수 있습니다. 중단 직전 생성·가입·제출의 실제 결과를 확인하고 재시도하세요.

## 구성

```text
React 대시보드 ← SSE: 유형별 활동·상태·발견 사항
      ↓ HTTP: 설정 / 실행 / 일시정지 / 종료·피드백 / 긴급중단
Express + Manager ─ SQLite
      ↓ 단일 실행 잠금, IPC
에이전트별 Node worker A~E
      ├─ OpenAI Agents SDK · 본인 대화·제한된 도구
      ├─ Playwright · 독립 Chromium과 로그인 프로필
      └─ 종료 시 도구 없는 별도 피드백 요청
```

보안·복구 수정: 관찰 노드에 묶인 ref와 의미 재검사, 위험 form/Enter 검사, 입력 타입 정규화, 최초 탐색 실패 정리, DB 최신 선택 동률 처리, 환경변수 최소 전달, 올바른 입력 오류 응답.

서버는 127.0.0.1에만 바인딩합니다. 원격 호스팅·다중 사용자 인증 서버가 아닙니다. 에이전트별 프로세스·프로필 분리는 OS 보안 샌드박스와 다릅니다.

## 키와 데이터

- .env, .local, node_modules, dist는 Git에서 제외합니다. 이 저장소는 Public입니다.
- worker에는 필요한 OS·애플리케이션 변수만 전달합니다. worker가 .env를 다시 읽지 않습니다.
- Chromium에는 모델 키·불필요한 비밀을 전달하지 않습니다.
- API store=false, SDK tracingDisabled=true입니다. 모든 형태의 외부 보존이 없다는 뜻은 아닙니다.
- DOM 텍스트·프롬프트·도구 결과는 OpenAI API로 전송됩니다.
- .env는 평문이며 Git 제외는 암호화가 아닙니다.
- 선택 저장된 화면 본문·trace·DB·프로필에는 민감 정보가 있을 수 있습니다.
- Windows 자격 증명 저장소 연동은 아직 없습니다.

자세한 내용: [SECURITY.md](docs/SECURITY.md).

## 검증 범위

타입 검사·빌드, 로컬 fixture와 모의 API를 이용한 안전성·직렬 실행·텍스트 보고·종료/피드백·실패 대체·초기화 검증을 수행합니다. 구체적인 결과는 TEXT_REPORTING 문서에 있습니다.

실제 OpenAI 모델의 탐색 품질·비용·권한 및 모여 로그인·업무 흐름은 아직 검증하지 않았습니다. 전문 보안 진단이나 결정적인 회귀 테스트를 대체하지 않습니다.

자동 병렬·DAG·자동 메시지·시나리오 라이브러리·네이티브 모바일·영상 스트리밍·과거 결과 조회 UI는 포함하지 않습니다.
