# 새 컨텍스트에 붙여넣을 프롬프트

아래 블록을 새 대화에 붙여넣고 마지막 ‘이번 작업’을 원하는 내용으로 바꾼다. 최신 소스 ZIP 또는 실제 코드가 있는 로컬 저장소를 함께 제공한다. 이 Markdown만으로 소스가 자동 전달되는 것은 아니다.

```text
multi-agent-qa 프로젝트를 이어서 작업해줘.

먼저 프로젝트 루트의 README.md와 다음 문서를 순서대로 읽어줘.
1. docs/PROJECT_CONTEXT.md
2. docs/ARCHITECTURE.md
3. docs/PROMPTS.md
4. docs/SECURITY.md
5. docs/HANDOFF.md
6. docs/WORKLOG.md

배경:
- 첫 테스트 대상은 모여 https://moyeo-web.vercel.app/login 이지만 다른 웹 서비스에도 쓸 로컬 QA 플랫폼이다.
- 원래는 병렬 멀티 에이전트를 검토했지만 MVP는 사용자가 5명 A~E에 직접 프롬프트를 주고 실행 버튼을 눌러 한 번에 한 명씩 실행하도록 확정했다.
- 실행 순서는 자유롭다. 자동 대기열·DAG·자동 메시지·역할 고정은 추가하지 않는다.
- 같은 테스트의 같은 에이전트는 대화를 이어가고, 새 테스트에서는 5명의 대화를 초기화한다.
- 현재 구현은 새 테스트에서도 역할·프롬프트·로그인 프로필을 유지한다. 원격 서비스 데이터를 지우는 동작은 없다.

현재 기술:
TypeScript/Node.js, React/Vite, Express, OpenAI Agents SDK, Playwright, SSE, Node SQLite.
에이전트별 Node 자식 프로세스와 Chromium 프로필을 사용한다.
AI는 DOM 텍스트와 요소 ref로 행동하며, 스크린샷은 사용자 미리보기/증거용이다.

상태:
- 구현 기준 커밋은 8e140e2이고 인계 문서가 추가됐다. 실제 현재 HEAD와 git status를 확인해줘.
- 저장소는 https://github.com/ohujj/multi-agent-qa 이며 Public이다.
- GitHub push는 Windows 인증 저장소 접근 거부로 미완료였다. clone만으로 최신 코드가 있다고 가정하지 말고 내가 전달한 소스/작업 사본을 확인해줘.
- 빌드와 로컬 fixture + 모의 API smoke는 통과했지만 실제 OpenAI 모델과 모여 로그인/업무 흐름은 미검증이다.
- 커밋된 자동 테스트 스위트는 없다. 이전 .local smoke 스크립트를 새 clone에 있다고 가정하지 마.
- 사용자 호스트에서 서버가 계속 켜져 있다고 가정하지 말고 현재 환경에서 기동을 확인해줘.

키 관리:
- 실제 키·토큰·비밀번호를 채팅으로 요구하거나 출력하지 마.
- 현재는 전용 OpenAI 프로젝트 키를 사용자가 로컬 .env 또는 실행 프로세스 환경변수에 입력하는 방식이다.
- .env와 .local은 Public 저장소에 넣지 않는다. VITE_ 변수나 프런트엔드에 키를 넣지 않는다.
- worker에 process.env 전체를 상속하는 현재 동작이 있다. 필요한 비밀만 전달하는 개선은 별도 검토 대상이다.
- Windows 자격 증명 저장소 연동은 제안일 뿐 아직 구현되지 않았다.
- 실제 환경변수 파일을 읽거나 키 관리 방식을 바꿔야 한다면 이번 요청의 범위와 사용자 지시를 먼저 확인해줘.

작업 방식:
- 문서와 실제 소스를 대조하고 확정 요구·구현 사실·제안을 구분해줘.
- 변경 전 관련 API, Manager, Worker, 브라우저 도구, 공유 타입과 UI 경로를 확인해줘.
- 모의 검증과 실제 서비스 검증을 구분하고, 쓰기 작업의 원격 반영 여부를 확인해줘.
- 불필요한 리팩터링·의존성 업데이트·병렬화는 하지 말고 요청 범위에 맞춰 작업해줘.
- 먼저 현재 상태와 이번 작업 범위를 짧게 요약하고 필요한 구현·검증을 진행해줘.
```

- README.md 및 docs 전체
- server, shared, src, scripts와 프로젝트 설정·package-lock을 포함한 최신 소스
- 필요한 경우 키/계정/개인정보가 제거된 오류 메시지

.env, .local, 로그인 프로필, 실제 API 키와 토큰은 첨부하지 않는다.
